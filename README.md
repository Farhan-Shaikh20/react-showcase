# 🚀 React Showcase

> A modern React learning project built with **React + Vite** to demonstrate core React concepts through interactive examples, including Components, Props, Hooks, Forms, Conditional Rendering, and Routing.

---

## 📖 About the Project

**React Showcase** is a hands-on React practice application created to learn and demonstrate fundamental concepts of component-based frontend development.

Instead of studying each concept separately, this project brings multiple React concepts together in one interactive application. Each concept can be explored through the sidebar navigation, making the project useful both as a learning project and as a quick reference for React fundamentals.

The application is intentionally simple and educational, focusing on how components, state, events, conditional logic, forms, and route-based navigation work together.

## 🏗️ Architecture / Workflow

The application follows a simple component-based React structure.

```text
React Showcase
│
├── App.jsx
│   └── Defines routes and main application layout
│
├── components/
│   ├── Sidebar.jsx
│   └── ErrorBoundary.jsx
│
├── concepts/
│   ├── Props.jsx
│   ├── UseStates.jsx
│   ├── UseEffects.jsx
│   ├── ConditionalDemo.jsx
│   └── Forms.jsx
│
└── pages/
    ├── Home.jsx
    ├── About.jsx
    └── Cheatsheet.jsx
```

Each concept is implemented as a separate component, making the project easy to understand, maintain, and extend.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Farhan-Shaikh20/react-showcase.git
```

### 2. Navigate to the Project

```bash
cd react-showcase
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Then open the local URL shown in the terminal.
